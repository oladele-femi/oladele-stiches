Website Architecture

Document Object Model (DOM) Structure

Visualizing how every HTML page in Oladele Stitches is organized as a tree of nodes in the browser DOM.

HTML Document Tree

Click "Run Live DOM Count" to inspect the active nodes on this page with JavaScript.

  • document Root Document Object
    • <html> Root HTML element
      • <head> Metadata & External CSS
        • <meta> Charset & responsive viewport
        • <title> Page title
        • <link rel="stylesheet" href="css/styles.css"> External CSS file
      • <body> Visible page content
        • <header class="site-header">
          • <nav / ul class="nav-links"> Consistent 6-page link structure
        • <div class="marquee-bar">
          • <marquee> Scrolling event announcement on all pages
        • <main> Page-specific sections
          • <section class="hero / page-banner"> Introductory banner
          • <section class="section"> Products / Trustees / Events / Form / DOM Tree
        • <footer class="site-footer">
          • <ul class="footer-links"> Consistent footer navigation links
        • <script src="js/main.js"> Interactive JavaScript features
